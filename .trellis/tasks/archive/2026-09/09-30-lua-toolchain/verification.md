Each package includes matching Lua, Flutter, and app libraries. The HAPs also
include `libc++_shared.so`. APK inspection found no debuggable flag; both HAP
manifests contain `app.debug=false` and `app.buildMode=release`.

Build commands:

```text
flutter build apk --release --target lib/main.dart --target-platform android-arm64 --no-pub
flutter build hap --release --target lib/main.dart --target-platform ohos-arm64 --no-pub
flutter build hap --release --target lib/main.dart --target-platform ohos-x64 --no-pub
```

Logs are local generated files at `build/release-android-arm64.log`,
`build/release-ohos-arm64.log`, and `build/release-ohos-x64.log`.
