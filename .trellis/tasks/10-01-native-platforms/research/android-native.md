## Corrected Gap

The first fresh release APK contained Lua ARM64/x86_64 ELF LOAD segments aligned
to `0x1000` (4 KiB). Flutter's corresponding libraries were already aligned to
`0x10000`. Android devices with 16 KiB memory pages require compatible native
ELF segment alignment, independently of APK ZIP alignment.

Added NDK 27's `-DANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON` in the application's
default external CMake arguments. The NDK's existing toolchain applies
`-Wl,-z,max-page-size=16384` to ARM64/x86_64. The shared C sources are unchanged
by this Android correction.
