## 步骤

1. 核心最小离线门控 patch 与回归交主代理统一集成。
2. 确认签名材料、JBR/SDK与生成元数据，仅修实际构建错误。
3. 等待终端子任务、内容子任务与核心集成完成后构建最终 APK/HAP。
4. 检查原生 ABI/导出/对齐/ArkTS/签名，记录产物哈希。
5. 可用且授权时尝试 adb/hdc 覆盖安装并验证实际双终端/离线入口；失败不卸载应用。
6. 汇总证据、外部阻塞与发布签名限制，分批提交实际修复。

## 验证与提交

遵循父任务 implement.md 中的具体命令及质量门禁。所有执行命令、结果、产物与阻塞写 verification.md。主代理显式按文件暂存并使用 Conventional Commits；不自行并发 Git 提交。
